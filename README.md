2D Game Framework (Work in Progress)
A custom 2D game framework built entirely in vanilla JavaScript using the HTML Canvas API.
The goal of this project is to explore and implement the core building blocks of a real game engine — rendering, coordinate systems, object management, animation, and physics — all from scratch and without external libraries.
This project is developed step by step with a strong focus on clean architecture, modular design, and clarity.
Alongside the code, I am writing a tutorial series documenting the development process and explaining the technical decisions behind each component.
Current Features
- Basic rendering system
- Drawing geometric shapes (rectangles, circles, polygons)
- Modular project structure
- Example usage demonstrating the rendering pipeline
Planned Features
- JavaScript-based game loop
- Animation system
- Basic physics and motion
- Collision detection
- Scene and object management
- Rendering optimizations
Project Goals
- Gain a deeper understanding of low-level game engine architecture
- Strengthen JavaScript skills beyond typical web development
- Build a solid foundation for future game-related projects
- Demonstrate system design and problem-solving abilities to potential employers
Project Status
This project is still in early development and will continue to evolve over time.
